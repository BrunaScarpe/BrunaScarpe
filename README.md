# 👩🏻‍💻 Bruna Scarpe

**`Analista de Dados`**

Sou pós-graduada em Data Analytics e atuo na área de Dados desde 2021, com experiência em análise de dados, Business Intelligence e desenvolvimento de soluções para apoiar decisões estratégicas.

Tenho experiência com **SQL, Power BI e Python**, atuando desde a extração, tratamento e análise dos dados até a construção de dashboards, indicadores e automações.

Meu trabalho é voltado à transformação de dados em informações claras e relevantes para o negócio, apoiando o acompanhamento de resultados, identificação de oportunidades e melhoria de processos.

Estou constantemente aprimorando meus conhecimentos em novas tecnologias e boas práticas de análise de dados, buscando evoluir tanto tecnicamente quanto na capacidade de transformar dados em soluções que gerem valor para o negócio.
